# Changelog

Notable changes to `lanstash-domain`.

## 0.1.0 (unreleased)

First version.

- HTTP heads, byte ranges and chunked bodies; request routing per service (`Profile`, `Profiles`).
- The segment and journal formats of the stash, extents and eviction choices.
- The nginx cache file format.
- Checksums (CRC-32, MD5, SHA-1), base64, inflate and gzip.
- DNS wire format, including reverse (PTR) queries, and TLS server names.
- QR codes with SVG and terminal rendering.
- ZIP entries and RSA public-key encryption (PKCS#1 v1.5).
- Game names, JSON and image types.
