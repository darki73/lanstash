# Changelog

Notable changes to `lanstash-epic`.

## 0.1.0 (unreleased)

First version.

- Which Epic requests are cached and under which game, CDN hosts included.
- `setup`: the `.cmd` that sets up a Windows PC so the Epic Games launcher downloads over plain HTTP; its words, paths and settings are checked types.
- `auth`: signing in with a code from Epic's own page, and the token requests and answers.
- `library`: an account's assets, catalog items, images and the catalog view.
- `manifest`: a binary build manifest's chunks, and a chunk checked against its SHA-1.
- `EpicPlatform`, the platform the composition root registers.
