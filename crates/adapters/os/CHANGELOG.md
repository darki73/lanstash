# Changelog

Notable changes to `lanstash-adapter-os`.

## 0.1.0 (unreleased)

First version.

- `command`: running a program with a time limit.
- `systemd`: asking systemd about a unit, its state and main process.
- `process`: a process's open files and its soft limit, from `/proc`.
- `pause`: the `Pause` port as a real sleep.
- `terminal`: the `Prompt` port on the terminal, secret answers read with echo off.
