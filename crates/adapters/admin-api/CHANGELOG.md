# Changelog

Notable changes to `lanstash-adapter-admin-api`.

## 0.1.0 (unreleased)

First version.

- The admin HTTP API under `/api/v1/` and the built-in status page, with a live status stream.
- Games per platform: builds, deletion and pruning of their parts.
- Accounts per platform: sign in (with a QR code where the platform has one) and sign out.
- Clients: who downloads what now, what each got over a range, and their names.
- Counters over time, top counters, the prefill runs that ended and the update history.
- DNS: the plan, its setup and applying it to the DNS server.
- The setup file that prepares a PC for a platform.
- The client the commands use to reach a running lanstash.
